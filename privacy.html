Политика конфиденциальности «Atlas Vsego Uploader»

Дата вступления в силу: 20 октября 2026 г.

«Atlas Vsego Uploader» — служебное приложение владельца YouTube-канала «Атлас Всего» (@atlasvsego). Оно работает только на компьютере владельца канала и используется исключительно для загрузки и публикации роликов этого канала через YouTube Data API.

Какие данные используются

  • Доступ к YouTube-аккаунту владельца канала (разрешения youtube.upload и youtube) — только чтобы загружать видео, обложки и управлять статусом публикации роликов канала «Атлас Всего».
  • Токен доступа хранится локально в защищённом хранилище (связке ключей macOS) на компьютере владельца и никуда не передаётся.

Чего приложение не делает

  • Не собирает данные зрителей и других пользователей.
  • Не продаёт, не передаёт и не раскрывает данные третьим лицам.
  • Не использует данные для рекламы.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use. Приложение использует YouTube API Services; см. также Политику конфиденциальности Google.

Отзыв доступа

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.

Контакты

Вопросы — через страницу вопросов проекта на GitHub или через YouTube-канал.

Privacy Policy — “Atlas Vsego Uploader”

“Atlas Vsego Uploader” is an internal tool of the owner of the YouTube channel “Атлас Всего” (@atlasvsego). It runs only on the channel owner's computer and is used solely to upload and publish this channel's videos via the YouTube Data API. It accesses only the channel owner's YouTube account (scopes youtube.upload and youtube); the access token is stored locally in the macOS Keychain and is never shared. The app does not collect data about viewers or other users, does not sell or share any data, and does not use data for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: via the project's GitHub issues page or the YouTube channel.
