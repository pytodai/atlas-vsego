Privacy Policy — “World on a Map uploader”

Effective date: October 22, 2026.

“World on a Map uploader” is an internal tool of the owner of the YouTube channel “World on a Map” (@worldonamap). It runs only on the channel owner's computer and is used solely to upload and schedule this channel's videos, read this channel's analytics and reply to comments on this channel via the YouTube Data API and YouTube Analytics API.

Data used

  • Access to the channel owner's YouTube account only — to upload videos, manage their publishing status, read channel analytics and post replies to comments on the channel's own videos.
  • The access token is stored locally in the macOS Keychain on the owner's computer and is never shared.

What the app does not do

  • It does not collect data about viewers or other users beyond the public comments it replies to.
  • It does not sell, share or disclose any data to third parties.
  • It does not use data for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see also the Google Privacy Policy and the YouTube Terms of Service.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Via the project's GitHub issues page or the YouTube channel.
